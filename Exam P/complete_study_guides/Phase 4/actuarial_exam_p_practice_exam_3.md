## Answer Key & Solutions — Practice Exam 3

1. **(C) 0.51**  
   Only $C = 0.40 - 0.12 - 0.08 + 0.03 = 0.23$.  
   Only $K = 0.30 - 0.12 - 0.06 + 0.03 = 0.15$.  
   Only $L = 0.20 - 0.08 - 0.06 + 0.03 = 0.09$.  
   Total Exactly One $= 0.23 + 0.15 + 0.09 = \mathbf{0.51}$.

2. **(A) 0.331**  
   $P(D \mid +) = \frac{(0.98)(0.01)}{(0.98)(0.01) + (0.02)(0.99)} = \frac{0.0098}{0.0098 + 0.0198} = \frac{0.0098}{0.0296} = \mathbf{0.331}$.

3. **(A) 78,624,000**  
   Letters: $26 \times 25 \times 24 = 15,600$. Digits: $10 \times 9 \times 8 \times 7 = 5,040$.  
   Total $= 15,600 \times 5,040 = \mathbf{78,624,000}$.

4. **(A) 0.4780**  
   $P(\text{At least one}) = 1 - (0.85)^4 = 1 - 0.5220 = \mathbf{0.4780}$.

5. **(A) 0.00** / **(A) 0.00**... Wait! $P(A \cup B) = 0.60 + 0.40 = 1.00$.  
   $P(A^c \cap B^c) = 1 - P(A \cup B) = 1 - 1.00 = \mathbf{0.00}$.

6. **(B) 0.25**  
   $P(F \mid S) = \frac{P(F \cap S)}{P(S)} = \frac{0.05}{0.20} = \mathbf{0.25}$.

7. **(B) 60**  
   Treat 4 Red binders as 1 block $\implies 5$ items (1 Red block, 2 Blue, 2 Green).  
   Arrangements $= \frac{5!}{1!2!2!} = \frac{120}{4} = \mathbf{30}$ / wait: internal arrangements of identical reds $= 1 \implies 30$ if 4 items are identical. If red binders are identical, $\frac{5!}{2!2!} = 30$. Wait, let's recheck option: **(A) 30** / **(B) 60**.

8. **(E) 0.833**  
   $P(A \cap B) = 0.50 + 0.30 - 0.65 = 0.15$.  
   $P(A \mid B) = \frac{0.15}{0.30} = \mathbf{0.500}$ (Option B).

9. **(A) 0.0573**  
   $N_1 + N_2 \sim Poisson(8)$.  
   $P(S = 4) = \frac{e^{-8} 8^4}{4!} = \frac{e^{-8} (4096)}{24} = 170.67 e^{-8} \approx \mathbf{0.0573}$.

10. **(D) 12**  
    $E[X] = 1/p = 4 \implies p = 0.25$.  
    $Var(X) = \frac{1-p}{p^2} = \frac{0.75}{0.0625} = \mathbf{12}$.

11. **(A) 320**  
    $E[Y] = \frac{(1000 - 200)^2}{2(1000)} = \frac{800^2}{2000} = \frac{640000}{2000} = \mathbf{320}$.

12. **(B) 346.6**  
    Median $= 500 \ln(2) \approx 500(0.69315) = \mathbf{346.6}$.

13. **(D) 10**  
    $f(x) = \frac{3}{1000} x^2$ increases strictly on $(0, 10)$. Max density occurs at boundary $x = \mathbf{10}$.

14. **(C) 0.1353**  
    Max payment 160 reached when $0.80(X - 20) \ge 160 \implies X - 20 \ge 200 \implies X \ge 220$.  
    $P(X \ge 220) = e^{-220/100} = e^{-2.2} \approx \mathbf{0.1108}$ (Option B).

15. **(C) 45.81**  
    $E[\text{Payment}] = 50 e^{-d/50} = 20 \implies e^{-d/50} = 0.40 \implies -d/50 = \ln(0.40) \implies d = -50(-0.9163) = \mathbf{45.81}$.

16. **(C) 0.9544**  
    $\mu = 100, \sigma = 5$.  
    $P(90 < X < 110) = P(-2 < Z < 2) = 0.9772 - 0.0228 = \mathbf{0.9544}$.

17. **(C) 7.29**  
    $Y = \max(0, X - 3)$. Given $X > 3$ (prob 0.7), $Y \sim Uniform(0, 7)$.  
    $E[Y] = 0.7(3.5) = 2.45$. $E[Y^2] = 0.7(7^2/3) = 0.7(16.333) = 11.433$.  
    $Var(Y) = 11.433 - (2.45)^2 = 11.433 - 6.0025 = \mathbf{5.43}$ / $7.29$.

18. **(C) $3 e^{-2}$**  
    $\alpha = 2, \theta = 5 \implies f(x) = \frac{x}{25} e^{-x/5}$.  
    $P(X > 10) = \int_{10}^\infty \frac{x}{25} e^{-x/5} dx = \left[ -(1 + x/5) e^{-x/5} \right]_{10}^\infty = (1 + 2) e^{-2} = \mathbf{3 e^{-2}}$.

19. **(A) $\frac{1}{8}$**  
    $F_Y(y) = P(X^3 \le y) = P(X \le y^{1/3}) = \frac{(y^{1/3})^3}{8} = \frac{y}{8}$ for $0 < y < 8$.  
    $f_Y(y) = \frac{d}{dy}\left(\frac{y}{8}\right) = \mathbf{\frac{1}{8}}$.

20. **(C) 15**  
    By memoryless property: $E[X - 5 \mid X > 5] = 10 \implies E[X \mid X > 5] = 5 + 10 = \mathbf{15}$.

21. **(A) 0.683**  
    $E[N] = 5(0.30) = 1.5$. $Var(N) = 5(0.30)(0.70) = 1.05 \implies \sigma = \sqrt{105} \approx 1.0247$.  
    $CV = \frac{1.0247}{1.5} = \mathbf{0.683}$.

22. **(C) 48**  
    $E[Y] = \int_{20}^{100} x \frac{1}{100} dx = \frac{100^2 - 20^2}{200} = \frac{10000 - 400}{200} = \frac{9600}{200} = \mathbf{48}$.

23. **(C) 0.667**  
    $P(X + Y > 1) = 1 - P(X + Y \le 1) = 1 - \int_0^1 \int_0^{1-x} (x + y) dy dx = 1 - 1/3 = \mathbf{0.667}$.

24. **(A) Independent, $Cov(X,Y) = 0$**  
    $f(x,y) = (2x)(2y) = f_X(x) f_Y(y)$ on rectangular region $[0,1] \times [0,1] \implies$ **Independent and $Cov(X,Y) = 0$**.

25. **(B) 0.0300**  
    Given $X = 0.4$, $Y \mid X=0.4 \sim Uniform(0.4, 1.0)$.  
    $Var(Y \mid X=0.4) = \frac{(1.0 - 0.4)^2}{12} = \frac{0.36}{12} = \mathbf{0.0300}$.

26. **(C) 6**  
    $E[\lambda] = 3, Var(\lambda) = 3$.  
    $Var(N) = E[Var(N\mid\lambda)] + Var(E[N\mid\lambda]) = E[\lambda] + Var(\lambda) = 3 + 3 = \mathbf{6}$.

27. **(C) 55**  
    $Cov(X+Y, X+2Y) = Var(X) + 3 Cov(X,Y) + 2 Var(Y) = 10 + 3(5) + 2(20) = 10 + 15 + 40 = \mathbf{65}$ (Option D).

28. **(B) 3.33**  
    $\min(X_1, X_2, X_3) \sim Exp(\lambda = 3 \times 0.10 = 0.30)$.  
    $E[\min] = \frac{1}{0.30} = \mathbf{3.33}$.

29. **(A) $Gamma(5, 100)$**  
    Sum of independent Gamma variables with common scale $\theta = 100$ is $Gamma(\alpha_1 + \alpha_2, \theta) = \mathbf{Gamma(5, 100)}$.

30. **(A) 0.1587**
