### Question 30 (Topic 3: Multivariate Random Variables)

Using the Central Limit Theorem, calculate the approximate probability that the total aggregate claims for the 100 policies exceed 52,000.

## Answer Key & Solutions — Practice Exam 1

1. **(D) 52%**  
   $P(A \cup B \cup C) = (28 + 29 + 19) - (14 + 12 + 10) + 8 = 76 - 36 + 8 = 48\%$.  
   $P(\text{None}) = 100\% - 48\% = \mathbf{52\%}$.

2. **(C) 0.5476**  
   Total sample space $\binom{10}{4} = 210$.  
   Favorable: $\binom{4}{2}\binom{6}{2} + \binom{4}{3}\binom{6}{1} + \binom{4}{4}\binom{6}{0} = 6(15) + 4(6) + 1(1) = 90 + 24 + 1 = 115$.  
   $P = \frac{115}{210} = \mathbf{0.5476}$.

3. **(A) 0.1624**  
   $P(D \mid +) = \frac{P(+\mid D)P(D)}{P(+\mid D)P(D) + P(+\mid D^c)P(D^c)} = \frac{(0.95)(0.02)}{(0.95)(0.02) + (0.10)(0.98)} = \frac{0.019}{0.019 + 0.098} = \mathbf{0.1624}$.

4. **(C) 0.4651**  
   $P(\text{Claim}) = 0.30(0.01) + 0.50(0.04) + 0.20(0.10) = 0.003 + 0.020 + 0.020 = 0.043$.  
   $P(\text{High} \mid \text{Claim}) = \frac{0.20(0.10)}{0.043} = \frac{0.020}{0.043} = \mathbf{0.4651}$.

5. **(C) 0.30**  
   By independence of complements: $P(A^c \cap B^c) = P(A^c)P(B^c) = (1 - 0.40)(1 - 0.50) = 0.60 \times 0.50 = \mathbf{0.30}$.

6. **(C) 0.50**  
   $P(A \cup B) = P(A) + P(B) - P(A)P(B) \implies 0.70 = 0.40 + P(B)(1 - 0.40) \implies 0.30 = 0.60 P(B) \implies P(B) = \mathbf{0.50}$.

7. **(D) 0.8333**  
   $\sum p(x) = k(1^2 + 2^2 + 3^2 + 4^2) = 30k = 1 \implies k = 1/30$.  
   $P(X \ge 3) = \frac{3^2 + 4^2}{30} = \frac{25}{30} = \mathbf{0.8333}$.

8. **(C) 1260**  
   Arrangements with repeated items $= \frac{9!}{4!3!2!} = \frac{362880}{24 \times 6 \times 2} = \mathbf{1260}$.

9. **(D) 2**  
   $P(N = 2) = 3 P(N = 4) \implies \frac{e^{-\lambda}\lambda^2}{2!} = 3 \frac{e^{-\lambda}\lambda^4}{4!} \implies \frac{\lambda^2}{2} = \frac{3\lambda^4}{24} \implies \lambda^2 = 4 \implies \lambda = 2$.  
   For Poisson, $Var(N) = \lambda = \mathbf{2}$.

10. **(C) 5.0**  
    $P(X > 4) = (1 - p)^4 = 0.4096 \implies 1 - p = 0.8 \implies p = 0.2$.  
    $E[X] = \frac{1}{p} = \frac{1}{0.2} = \mathbf{5.0}$.

11. **(C) 0.6242**  
    $P(X \ge 2) = 1 - P(X=0) - P(X=1) = 1 - (0.8)^{10} - 10(0.2)(0.8)^9 = 1 - 0.10737 - 0.26844 = \mathbf{0.6242}$.

12. **(C) 1.00**  
    $\int_0^2 c(2x - x^2) dx = c [x^2 - x^3/3]_0^2 = \frac{4}{3}c = 1 \implies c = \frac{3}{4}$.  
    The density $f(x) = \frac{3}{4}x(2-x)$ is symmetric about $x = 1$. Hence, median $= \mathbf{1.00}$.

13. **(A) $10 e^{-0.4}$**  
    $E[Y] = \int_4^\infty (x - 4) \frac{1}{10} e^{-x/10} dx = 10 e^{-4/10} = \mathbf{10 e^{-0.4}}$.

14. **(B) 30**  
    $E[Y] = \int_0^{60} S_Y(y) dy = \int_0^{60} P(X - 20 > y) dy = \int_0^{60} \frac{100 - (20 + y)}{100} dy = \frac{1}{100} \int_0^{60} (80 - y) dy = \frac{1}{100} [80(60) - 1800] = \mathbf{30}$.

15. **(A) $100(1 - e^{-0.5})$**  
    $E[X \wedge 50] = \int_0^{50} S(x) dx = \int_0^{50} e^{-x/100} dx = 100(1 - e^{-50/100}) = \mathbf{100(1 - e^{-0.5})}$.

16. **(C) 4000**  
    Given $X > 2000$, $(X - 2000) \sim Uniform(0, 8000)$.  
    $E[X - 2000 \mid X > 2000] = \frac{8000}{2} = \mathbf{4000}$.

17. **(C) 192**  
    $E[X] = \alpha\theta = 12$, $Var(X) = \alpha\theta^2 = 48$.  
    $E[X^2] = Var(X) + (E[X])^2 = 48 + 144 = \mathbf{192}$.

18. **(B) 0.0668**  
    $Z = \frac{650 - 500}{100} = 1.50$.  
    $P(Z > 1.50) = 1 - \Phi(1.50) = 1 - 0.9332 = \mathbf{0.0668}$.

19. **(C) $\frac{1}{4\sqrt{y}}$**  
    $F_Y(y) = P(X^2 \le y) = P(X \le \sqrt{y}) = \frac{\sqrt{y}}{2}$.  
    $f_Y(y) = \frac{d}{dy} \left(\frac{\sqrt{y}}{2}\right) = \mathbf{\frac{1}{4\sqrt{y}}}$.

20. **(C) 0.3333**  
    Mean $= \int_0^1 x(2x) dx = \frac{2}{3}$. Mode $= 1$ (since density increases linearly up to $x=1$).  
    $|1 - 2/3| = \frac{1}{3} = \mathbf{0.3333}$.

21. **(B) 12.46**  
    $Y = 0.8 \max(0, X - 5)$. Memoryless property: $E[X - 5 \mid X > 5] = 20$.  
    $P(X > 5) = e^{-5/20} = e^{-0.25} \approx 0.7788$.  
    $E[Y] = 0.8 \times 20 \times e^{-0.25} = 16 e^{-0.25} \approx \mathbf{12.46}$.

22. **(C) 104.89**  
    $E[Y] = \int_{100}^{500} S(x) dx = \int_{100}^{500} e^{-x/200} dx = 200(e^{-0.5} - e^{-2.5}) = 200(0.60653 - 0.08208) = \mathbf{104.89}$.

23. **(C) $\frac{2}{3}$**  
    $\int_0^1 \int_0^1 c(x + 2y) dx dy = c \int_0^1 (1/2 + 2y) dy = c(1/2 + 1) = 1.5 c = 1 \implies c = \mathbf{\frac{2}{3}}$.

24. **(B) $4x(1 - x^2)$**  
    $f_X(x) = \int_x^1 8xy dy = [4xy^2]_x^1 = \mathbf{4x(1 - x^2)}$.

25. **(D) 0.7778**  
    $f_{Y\mid X}(y \mid x) = \frac{8xy}{4x(1-x^2)} = \frac{2y}{1-x^2}$ for $x < y < 1$.  
    For $x = 0.5$, $f(y \mid 0.5) = \frac{2y}{0.75} = \frac{8}{3}y$ for $0.5 < y < 1$.  
    $E[Y \mid X=0.5] = \int_{0.5}^1 y \frac{8}{3}y dy = \frac{8}{3} \left[ \frac{y^3}{3} \right]_{0.5}^1 = \frac{8}{9}(1 - 0.125) = \frac{7}{9} = \mathbf{0.7778}$.

26. **(D) 4.33**  
    $E[N\mid\Lambda] = \Lambda$, $Var(N\mid\Lambda) = \Lambda$.  
    For $\Lambda \sim Uniform(1, 5)$, $E[\Lambda] = 3$, $Var(\Lambda) = \frac{(5-1)^2}{12} = \frac{16}{12} = \frac{4}{3}$.  
    $Var(N) = E[Var(N\mid\Lambda)] + Var(E[N\mid\Lambda]) = 3 + \frac{4}{3} = \frac{13}{3} = \mathbf{4.33}$.

27. **(C) 4036**  
    $Cov(M, N) = 0.64 \sqrt{1600} \sqrt{900} = 0.64(40)(30) = 768$.  
    $Var(M+N) = 1600 + 900 + 2(768) = \mathbf{4036}$.

28. **(C) 0.4690**  
    $F(3) = 1 - e^{-3/2} = 1 - 0.22313 = 0.77687$.  
    $P(\max(X_1, X_2, X_3) < 3) = [F(3)]^3 = (0.77687)^3 = \mathbf{0.4690}$.

29. **(B) 3.33**  
    Minimum of independent exponentials is Exponential with rate $\lambda = \lambda_1 + \lambda_2 = 0.10 + 0.20 = 0.30$.  
    $E[W] = \frac{1}{0.30} = \mathbf{3.33}$.

30. **(A) 0.0228**  
    $E[S] = 100(500) = 50,000$. $Var(S) = 100(100^2) = 1,000,000 \implies \sigma_S = 1000$.  
    $P(S > 52000) = P\left(Z > \frac{52000 - 50000}{1000}\right) = P(Z > 2.00) = 1 - 0.9772 = \mathbf{0.0228}$.
